## EasyApp / BBL-Common

This software was originally developed in 2010-11 as an open source project at the University of Pennsylvania's [Brain Behavior Lab](https://www.med.upenn.edu/bbl).  It served as an underlying utility library for per-study data access website projects.  The goal was to streamline the creation of individual Struts2-based websites, each providing data entry/ingestion and access by study managers (typically grad students/post-docs).

Later, it served as a core dependency of a [custom wedding website](http://mrfeelings.com/wedding) and a few other small projects.

In 2026, it received a long-needed upgrade to the latest Struts and other dependencies, resolving security issues, and making it compatible with the Servlet 6.1 Spec.

Please see the [JavaDoc API](api/index.html) for more information.
